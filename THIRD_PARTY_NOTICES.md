# Third-party code and example assets

`src/vendor/analyze.js`, `src/vendor/convert.js`, and `src/vendor/usc.ts` contain the portable SUS analyzer and SUS→USC conversion from [sonolus-pjsekai-engine](https://github.com/NonSpicyBurrito/sonolus-pjsekai-engine/tree/0f6f37fc9b512b9d156ec4c00d998fe3916b157d), pinned to commit `0f6f37fc9b512b9d156ec4c00d998fe3916b157d`. JavaScript files are TypeScript-stripped source with no engine assets or gameplay runtime. The source is provided under the MIT license below.
